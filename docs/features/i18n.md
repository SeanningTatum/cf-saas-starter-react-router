# Languages

The app speaks English and Chinese (`supportedLngs` in `app/lib/constants/i18n.ts`). The server picks the locale from the locale cookie or the request headers (`app/i18n/i18n.server.ts`); the language switcher (`app/components/language-switcher.tsx`) changes it through `POST /api/set-locale` (`app/routes/api/set-locale.ts`).

## Why

- **Only the public pages have a locale prefix.** Home, sign-in and sign-up answer at the root in the default locale and again under `/:lng`, so a search engine can index each language. The API routes, the dashboard and the admin area have no prefix and translate in the browser only; the dashboard and admin layouts also require a session.
- **A route lists every namespace its page renders.** A route's `handle.i18n` is what loads on a direct or hard navigation, so it names the namespaces of the components it renders too. The kitchen sink lists `admin` because `SiteHeader` takes its GitHub link text from it.
